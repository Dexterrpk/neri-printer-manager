# Autoria

O **Neri Printer Manager** é um projeto criado e mantido por **Cleiton Neri**, sob a identidade **Neri Infotech**.

A ideia nasceu de problemas reais de suporte em Linux Mint: impressoras que instalam mas não imprimem, filas retidas, CUPS quebrado, filtros, HPLIP, backends USB, compartilhamentos SMB e diagnósticos que normalmente exigem vários comandos manuais.

O objetivo do projeto é transformar esse trabalho técnico em um fluxo simples:

**diagnosticar → explicar → corrigir somente o necessário → validar → testar**.

A prioridade é resolver problemas de impressão sem interferir na infraestrutura de rede. O projeto não foi pensado para administrar firewall, DNS, DHCP, gateway, roteamento, Zentyal ou outros hosts.
